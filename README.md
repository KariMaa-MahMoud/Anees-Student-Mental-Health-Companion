# Anees-Student-Mental-Health-Companion

اسم المشروع (عربي): مَشروع "أنِيس" – رفيق الطالب للصحة النفسية

Project Name (English): Anees – Student Mental Health Companion

موجز المشروع للتقديم الرسمي:
"تطبيق أنِيس (Anees) هو رفيق رقمي تفاعلي يعتمد على الذكاء الاصطناعي وأتمتة العمليات ،صُمم ليكون المساحة الآمنة للطلاب في المدارس المصرية (K-12). يقوم التطبيق بتقييم الحالة النفسية للطلاب بشكل دوري وغير مباشر من خلال محادثات تفاعلية تناسب كل مرحلة عمرية، مما يقدم نظام إشعار وتدخل مبكر للإخصائي النفسي أو ولي الأمر والمدرسة مع الحفاظ التام على خصوصية الطالب."
